    Folders and jobs

      Adding a folder indexes it straight away. While watching, a new folder is picked up within one scan. An unticked folder stops being maintained but keeps what is already indexed.

      Outlook mail

      Sync mail reads your PST/OST directly, so close Outlook first — it locks the file, and this route cannot open messages afterwards. Sync via Outlook needs Outlook running, is slower, and records the item ids that let you open an email or its attachments by double-clicking. A limit stops early and leaves deletions alone; set 0 to sync everything.
